🦟 Panduan & Aturan Permainan

1. Posisikan Tangan di Depan Kamera Pastikan tangan terlihat jelas di webcam dengan pencahayaan ruangan yang cukup. Kursor bidikan lingkaran biru/cyan akan mengikuti gerakan telapak tanganmu.
2. Gestur Mengepal / Tepuk (Fist Grab) Arahkan lingkaran bidikan ke nyamuk pembawa jawaban kuis. Segera kepalkan tanganmu (atau lakukan gerakan tepuk). Indikator akan berubah merah menyala dan menangkap nyamuk!
3. Aturan Skor - Tangkapan BENAR: +10 Poin
- Tangkapan SALAH: -2 Poin (skor minimal 0)
4. Dukungan Touch & Mouse Jika webcam terkendala, kamu juga bisa langsung menyentuh layar atau mengklik nyamuk dengan mouse.
100% GRATIS & SELAMANYA Bebas Biaya Server

Publikasikan Game Secara Online

Siswa dan rekan guru dapat memainkan game ini langsung lewat link URL internet

File HTML Mandiri Siap Pakai

Unduh file index.html tunggal ini untuk langsung diunggah ke hosting gratis.

Paling Instan: Cukup Drag & Drop (1 Menit Live!) Rekomendasi
  1. Klik tombol hijau "Unduh File index.html" di atas.
  2. Buat sebuah folder baru di komputer Anda (misal beri nama folder: tepuk-nyamuk), lalu pindahkan file index.html ke dalam folder tersebut.
  3. Buka halaman: https://app.netlify.com/drop .
  4. Tarik (*drag and drop*) folder tersebut ke kotak di layar Netlify.
  5. Game Anda langsung online dengan link HTTPS gratis (misal: https://tepuk-nyamuk-kka.netlify.app)!
Buka Netlify Drop Sekarang
GitHub Pages (100% Gratis Selamanya)
  1. Buka GitHub.com dan buat repositori baru (misal: tepuk-nyamuk-kka, pilih Public).
  2. Upload file index.html ke repositori tersebut.
  3. Buka tab Settings di repositori > klik menu Pages di sebelah kiri.
  4. Pada bagian Branch, pilih main (atau master) dan folder / (root), lalu klik Save.
  5. Tunggu 1–2 menit, game aktif di: https://[username].github.io/tepuk-nyamuk-kka/
Vercel (Performa Cepat & Domain Gratis .vercel.app)
  1. Buka Vercel.com dan masuk menggunakan akun GitHub Anda.
  2. Klik tombol Add New... lalu pilih Project.
  3. Klik Import pada repositori GitHub game ini.
  4. Pada bagian Configure Project, pastikan pengaturannya seperti ini:
    • Framework Preset: Vite
    • Root Directory: ./ (biarkan default)
    • Build Command: npm run build (otomatis)
    • Output Directory: dist (otomatis)
    • Environment Variables: Kosongkan (tidak butuh API key)
  5. Klik tombol Deploy. Vercel akan otomatis memproses dan memberikan link HTTPS gratis (misal: https://tepuk-nyamuk-kka.vercel.app)!
Cloudflare Pages (Bandwidth Tanpa Batas)
  1. Masuk ke Cloudflare Dashboard > menu Workers & Pages.
  2. Klik Create application > tab Pages.
  3. Pilih opsi Upload assets dan seret folder berisi file index.html.
  4. Klik Deploy site. Link aktif langsung diberikan!
Mengapa Harus Menggunakan Layanan di Atas? Browser modern (Chrome, Edge, Safari) hanya mengizinkan akses kamera webcam pada situs dengan koneksi terenkripsi aman (HTTPS). Keempat layanan gratis di atas sudah otomatis menyediakan sertifikat SSL/HTTPS gratis 100% tanpa biaya tambahan!
